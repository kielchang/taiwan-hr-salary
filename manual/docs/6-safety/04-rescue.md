📍 位置：三種救法各自入口見下表。

改錯東西不用慌——先對照下表，挑對救法，影響越小的方法越優先：

| 出了什麼事 | 用哪個救法 | 到哪裡做 |
| --- | --- | --- |
| 改錯**一筆**資料（薪資、員工欄位、眷屬） | 從異動紀錄按「回復」 | 基本資料 → 異動紀錄 |
| 改錯**當月加班／請假／獎金** | 直接回「薪資結算」把數字改回（此類無回復紀錄） | [輸入當月異動](/monthly/input) |
| **確認錯了月份**，或確認後才發現數字要改 | 取消確認，改完再重新確認 | 每月作業 → 查核與確認 |
| **大範圍弄壞**（誤刪多筆、設定改亂、資料狀態說不清） | 用備份檔整份還原 | 系統設定 → 資料與安全 |

## 救法一：改錯一筆 → 從異動紀錄回復

**時機**：單筆改錯，而且記得（或找得到）是哪一筆變更。

1. 點「基本資料」→「**異動紀錄**」分頁，用搜尋找到要撤銷的那筆變更（每筆都記著誰、何時、把什麼從多少改成多少）。
2. 按該列的「**回復**」鈕，確認後系統把資料還原成變更前的值，並**另記一筆**回復紀錄。

**注意**：

- 逐欄編輯類（薪資、員工欄位、眷屬）有記前後值，**可回復**；新增、刪除、批次、月結確認類**沒有「回復」鈕**，要更正請手動辦理對應情境把資料改回來。當月加班、請假、獎金等月結異動無回復紀錄，直接回「薪資結算」把數字改回。
- 當月**代扣稅**的變更可回復，但在「系統設定 → 資料與安全」的變更紀錄，不在基本資料的異動紀錄。
- 該筆變更落在**已確認月份**時，回復會被鎖定擋下——先用救法二取消確認，再回來按回復。

## 救法二：確認錯月 → 取消確認

**時機**：按了「確認本月結算」之後才發現月份選錯、或還有數字要改。已確認的月份資料是凍結的，所有修改都會被擋下，必須先解凍。

1. 到「每月作業 → **查核與確認**」，確認頁面右上的發薪月份是要解凍的那個月。
2. 按「**取消確認**」，該月解除凍結，留存的快照會一併移除。
3. 回到「薪資結算」或「基本資料」把該改的改好。
4. 改完回到查核頁，紅色錯誤清空後再按「**確認本月結算**」——快照會以最新資料重建。

**注意**：取消確認到重新確認之間，該月報表與薪資條的數字會跟著資料變動；已經發出去的文件，請在重新確認後重新產出一份。

取消確認流程見[確認本月結算](/monthly/confirm)。

## 救法三：大範圍弄壞 → 還原備份

**時機**：誤刪了很多筆、設定被改亂、或已經說不清哪些資料還是對的。前提是你有照第 1 節的習慣定期備份。

1. 到「系統設定 → **資料與安全**」分頁。
2. 按「**從備份檔還原**」，選取最近一份「弄壞之前」的備份檔。
3. 確認視窗會顯示**備份匯出時間**與員工人數、結算筆數、月份數——先核對這是不是你要回到的時間點，再按確定。
4. 還原後，從備份時間點**之後**做的所有輸入都要重新補做一次。

:::warning[還原會覆蓋目前所有資料，無法復原]

還原是「整份蓋回去」：目前系統裡的資料會**全部被備份檔取代**。如果現在的資料還有想保留的部分，先按「**匯出備份檔**（JSON）」把現況也存一份，再進行還原。

:::
