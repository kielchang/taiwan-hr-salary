## 先看一遍實際操作

<FlowPlayer name="review-confirm" />

當月異動輸入完、按下**完成輸入，前往查核**後，就到「查核與確認」頁把數字整個掃一遍——這是發薪前最後一道把關。頁面上方是摘要卡（**結算人數**、**應發總額**、**實發總額**、**公司總成本**）與**模擬年度**（以本月推估）卡，並顯示**環比**（和上月比）與**同比**（和去年同月比）——需有該月快照才有得比。

1. 先看**試算總覽**分頁：全公司逐員明細（月薪總額、加班費、獎金、應發、四項保費、所得稅、實發、公司成本），可搜尋、排序、匯出 CSV，確認前整表掃一眼。
2. 再看**統計查核**分頁：系統自動檢查法規與資料完整性——**紅色必須處理、黃色建議確認**。各分類合計與全公司的勾稽在「**統計數據勾稽**」卡，未分類金額以黃色徽章列出。
3. 每項問題可按**前往修正**，直達該員工的異動對話框或基本資料，改完回來重看。
4. 需要的話用**獎金試算**分頁先試算獎金代扣（見下節「發獎金前先試算」），不寫回實際薪資。
5. 紅色錯誤全數排除後，再進行「確認本月結算（凍結）」。

:::warning[紅色錯誤擋確認]

只要還有紅色錯誤，或有人「需查稅額表填入代扣所得稅」，**確認本月結算**按鈕會停用，頁面上方會列出待處理清單。

:::

:::info[勾稽也順手看]

統計查核另有部門／成本中心勾稽與公司二代健保補充保費概算，發薪前順手核對。

:::
