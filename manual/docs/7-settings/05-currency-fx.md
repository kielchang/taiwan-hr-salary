---
title: 多幣別與匯率
---

「**幣別與匯率**」分頁＝**幣別與匯率維護中心**。外幣薪資與台幣**分開計算、視作獎金**，是獨立金流：**永不納入投保級距與勞健保**，台幣應發／實發也完全不受影響。

1. 按**啟用多幣別**開關（預設關＝全站不顯示外幣欄位、計算完全不含外幣）。
2. 新增幣別：填**代碼**（如 USD）、**名稱**、**符號**、**小數位**，按**新增幣別**；不用的幣別可**停用**。
3. 維護匯率：在**匯率（對台幣）**區選月份，逐幣別填「1 USD = 幾元」——匯率是逐月維護的。
4. 視公司政策決定兩顆開關：**外幣計所得稅**（開＝台幣約當併入獎金代扣建議與扣繳憑單）、**外幣計二代健保補充保費**（開＝併入補充保費基數）。兩者預設皆關。

:::warning[未設匯率＝台幣約當以 0 計]

某期沒填匯率時，該幣別當期會標「**未設匯率**」、台幣約當以 0 計（原幣別金額仍記錄）。發外幣前先確認當期匯率已填。

:::
