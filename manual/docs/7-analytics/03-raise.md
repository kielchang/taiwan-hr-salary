title: "調薪方案比較與試算（選讀）"
---

📍 位置：側邊欄 →「薪酬分析」。

年度或季度調薪季，用「**調薪試算**」先在沙盒把方案比到滿意，最後才按「核定套用」——這是全站唯一會把試算寫回實際薪資的動作，按下去之前都安全。

<MockScreen name="raise-plan" />

## 步驟

1. **情境設定**：選**期間別**（年度／季度）與**分配方法**——**一致調幅 %**（例如全員 +3%），或給一筆加薪池後**按本薪分配**／**按績效係數**／**merit matrix**（績效×級距，向高績效與級距偏低者傾斜）分配。
2. **逐人試算**：下方表格立即算出每人調前／調後與差額；用績效欄逐人指定評等，金額跟著變。按**匯出 CSV** 可把名單帶去主管會議。
3. **分配法比較**：看數字卡的**年化成本增額**（含雇主保費重算）與 Gini 前後變化；「**分配方法並排比較**」把四種分配法用同一預算跑一遍，比公平性與預算差異，挑最合適的一種。
4. **核定套用**：確定方案後按**核定套用此方案**，在視窗選**生效月份**——選**當月**＝確認後立即寫回（差額套在本薪）；選**未來月份**＝先存排程，到期後在「工作台」一鍵套用。按**確認核定寫回**完成，系統會留下稽核紀錄。

:::warning[套用前先把預覽看清楚]

核定套用＝寫回實際薪資，**無法一鍵回復**（稽核只留軌跡）；要復原須以[批次薪資](/hr-events/raise)或個別薪資情境手動改回，或還原備份。按下前務必逐人核對預覽的調後金額與生效月份；當月已確認結算時會被擋下——請改選未來生效月份存為排程，或先取消該月確認。

:::

## 注意

- **獎金／分紅試算永遠不寫回**：同群的獎金試算是純沙盒（決定池子大小、選分配法、可概估二代健保補充保費），逐人金額只供規劃與溝通，發放仍要回「薪資結算」輸入當月獎金。
- 要對整個單位加津貼或發區間補貼，請改用基本資料的「批次薪資」，不要用調薪試算硬湊。

試算滿意後要**實際生效**：見[幫員工調薪](/hr-events/raise)。
