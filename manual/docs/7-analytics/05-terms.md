---
title: "名詞快查"
---

看分析頁遇到不熟的名詞時，先查這張表拿白話一句；要更細的判讀區間，開系統內的「**指標說明**」分頁（13 條名詞都分「用途」與「怎麼看」，不講公式）。

| 名詞 | 白話一句 |
| --- | --- |
| compa-ratio（薪酬比較比） | 月薪 ÷ 級距中位；100% 剛好在中位，90%–110% 算健康。 |
| 市場 compa-ratio | 月薪 ÷ 市場中位，看對外競爭力；低於 90% 會標警示色（落後行情、留才風險）。 |
| 區間滲透率 | 在薪資帶裡走到哪：0% 在下限、接近 100% 表示快觸頂（再調就要升級距）。 |
| 百分位 P10–P90 | 把薪水由低到高排隊：P10＝排在前 10% 低的位置、P90＝前 90%，看頭尾差多大。 |
| 變異係數 CV | 薪資離散程度；越大代表大家的薪水差越多。 |
| Gini 係數 | 不均度：0＝人人同薪、越大越不均；看走勢與方案前後變化比看單一數值有意義。 |
| Lorenz 曲線 | Gini 的圖像版：曲線越偏離對角線越不均。 |
| 獎金/本薪比 | 獎金相對本薪的分量，看變動薪酬給得重不重。 |
| 變動薪酬比 | 獎金＋加班費等變動項占總薪酬的比例。 |
| 成本集中度（Pareto） | 少數高成本人力占總成本的比例；前 20% 占過半＝關鍵人力集中，留意接班與留任。 |
| 薪資壓縮 | 年資高但薪資未相稱；散布圖上偏右下的點，是調薪優先名單的線索。 |
| merit matrix（績效×級距） | 分配法之一：績效好、且在級距內偏低的人拿比較多。 |
| 分配方法 | 一筆池子怎麼分：均分／按本薪比例／按績效係數／merit matrix。 |
| 年化成本增額 | 調薪方案換算成一整年多花多少（含雇主保費重算）。 |
| 薪酬趨勢（歷期快照） | 每月結算後保存的彙總數字，累積起來畫走勢；只存彙總、不含個資。 |
| 年度預算使用率 | 目前年化成本（含試算中的調薪與獎金）占年度人事預算的比例，看會不會超支。 |

:::info[建議的閱讀順序]

先讀各分頁頂端的「重點意見（白話解讀）」拿結論，遇到不熟的名詞來這裡查一句白話，最後回圖表驗證。

:::
