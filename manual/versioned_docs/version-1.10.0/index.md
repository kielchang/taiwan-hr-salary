**最常查**：離職當月薪水([第3章](/hr-events/offboard))・取消確認改數字([第6章](/safety/rescue))・加退保名冊([第4章](/filing/enrollment))・第一次月結([跟我做](/quickstart/first-month))

- **找特定主題**：右上角搜尋（支援中文，如「加班」「備份」「匯率」）。
- **邊看邊操作**：各頁「開啟系統畫面 ↗」會另開系統對應頁；多數任務頁有**逐步操作示意**（與系統同一套元件排版、重點按鈕高亮，右上「開啟此作業」可直達）；重點欄位可直接試操作。
- **列印／匯出**：每頁右上有「🖨 列印此頁」，可直接印出或另存 PDF 留存。
