title: "完成初始設定"
---

📍 位置：第一次開啟系統自動進入；之後可從「使用說明」重跑

第一次開啟系統會自動進入初始設定，跟著五個步驟走完就能開始作業：**歡迎 → 公司設定 → 薪資結構預設 → 員工資料 → 完成**。115 年度的法定費率與投保級距已內建，只需要補上與貴公司有關的少數設定。

1. 選入門路徑：按「**載入範例公司體驗**」（內含約 60 名範例員工與 13 個月歷史（含已確認月份），會把「本月」設為示範月份，先熟悉操作）或「**從空白開始建立**」（直接建立自己公司的資料）。
2. 填**公司設定**三項：**本次要結算的發薪月份**、**職業災害保險費率**（%，依勞保局核定通知書填；不確定可先用全產業平均 0.21%）、**年資與特休的計算方式**（選「**依到職日**」（週年制）或「**固定基準日**」）。
3. 填**公司薪資結構預設**：新進員工建檔時自動帶入的固定津貼。**伙食津貼**已預先帶入 3,000（每月 3,000 元內免稅），可修改或留空。
4. 建立員工：空白模式在「**新增第一批員工**」填員工編號、姓名、部門、到職日與月薪（本薪，例如 35,000）後按「**加入**」；也可以先跳過，之後在「基本資料」再補。
5. 按「**開始使用**」完成設定，之後不會再進入這個流程。

:::warning[從空白開始＝清空現有資料]

在第一步選「**從空白開始建立**」會清空目前系統內的所有資料；若已經輸入過員工或薪資，請先到「系統設定」匯出備份，再重跑初始設定。

:::

:::info[之後都能改]

初始設定填過的每一項（費率、年資基準、津貼預設）之後都能在「系統設定」調整；也可以在「使用說明」頁按「**重新執行初始設定引導**」重跑一次。

:::
