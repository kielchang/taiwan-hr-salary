---
title: "認識畫面：功能選單與本月狀態"
---

📍 位置：登入後任何頁面

第一次進系統時，先花一分鐘認識畫面的兩個固定區域——左邊的功能選單、上方的本月狀態，之後每天作業都靠它們移動與判讀。

1. 畫面左邊是**功能選單**，依工作性質分區：**每月作業**（工作台、薪資結算）、**規劃與分析**（薪酬分析）、**報表與申報**、**主檔與設定**（基本資料、系統設定）、**說明**（使用說明、操作手冊、法規依據）。
2. 留意選單項目旁的小徽章：**例行**＝每月必做的工作；**試算**＝模擬試算用，怎麼玩都不會寫回實際薪資。
3. 畫面上方由左至右可以看到：
   1. 系統名稱旁若出現 **STAGE** 或 **DEV** 字樣，代表目前在預覽或測試環境；正式環境不會顯示。
   2. **導引**按鈕：帶你進「使用說明」啟動互動導覽。
   3. **本月**：目前結算中的發薪月份（下一節說明怎麼選）。
   4. 資料狀態：有錯誤時顯示紅色「**N 項待處理**」，否則顯示綠色「**資料正常**」。
   5. 月結狀態：**已確認**（本月結算已凍結）或**未確認**。

:::info[有些功能暫時看不到]

「出勤打卡」與「專案」功能目前未啟用，選單不會顯示這兩項；日後啟用時會自動出現，不影響薪資計算。

:::

:::info[手機/平板操作]

螢幕較窄時，左邊選單會收起來：按左上角**選單**按鈕從左側滑出，點旁邊的背景即可關閉。

:::
