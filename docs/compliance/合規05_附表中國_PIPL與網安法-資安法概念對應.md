# 合規05 附表：中國——PIPL 與網安法/資安法概念對應

> 前提定位見 [合規00](./合規00_系統定位與適用邊界聲明.md)。對策代號同合規02。

## 1. 適用性判斷

台灣公司使用本系統落入中國《個人信息保護法》（PIPL）的典型情境：(a) 在中國境內設有子公司/辦事處並處理其員工資料；(b) 於境內處理後將員工資料傳回台灣總部（跨境提供）。**本系統單機、資料不出裝置**，若操作發生在台灣、資料主體皆非中國境內個人，PIPL 不適用。

## 3. 網路安全法／資料安全法概念對應（一節帶過）

- **網安法**：義務主體為「網路運營者」。本系統無伺服器、不運營網路服務，系統面 N/A；使用組織的內網環境屬組織責任。
- **資安法（數據安全法）**：資料分類分級保護——薪資資料在境內子公司情境屬一般商業資料（非國家核心資料），落實面即 PIPL §51 的安全措施，對策同上。

## 4. 本系統特別議題

**單獨同意的取得介面**：PIPL 對敏感個資要求「單獨同意」（不能併入概括同意）。本系統作為工具無法代組織取得同意；能做的是（P1）在眷屬/敏感欄位編輯處放置提示文案，提醒操作者確認組織已完成單獨同意程序。同意書式樣由範本01 提供。

## 5. 小結

PIPL 對照的淨結論與 GDPR 高度重疊（安全措施、刪除、影響評估），增量只有兩點：**單獨同意**（程序＋範本承接）與**跨境提供**（本系統架構性不發生，風險全在匯出檔的人為流動——再次凸顯合規00 §5 匯出檔治理是組織側第一要務）。
