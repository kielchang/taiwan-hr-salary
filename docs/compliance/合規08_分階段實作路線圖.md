## 2. P0 清單（1.12.0）

### 2.1 合規文件體系（本目錄 9 檔）
- **目標**：十一項技術措施 #2/#3/#11、GDPR Art.30 的文件化基礎。**差距回鏈**：全表。
- **驗收**：合規00～08 落檔；附錄C C6 連結；README 指向。

### 2.2 薪資條批次匯出外洩修補（W3, W11 部分）
- 寄送清單 CSV 移除「PDF密碼」欄（`buildDispatchCsv` 純函數化）；mailto 內文改「密碼規則請洽人事」；畫面說明文字同步。
- **驗收**：ZIP 內任何檔案與 mailto 內文不含密碼提示；`tests/payslipDispatch.test.ts` 綠。

### 2.3 示範資料身分證去識別（W4；ADR-043）
- seed 8 筆＋demoCompany 62 筆改「regex 合法＋檢查碼不合法」Z 段測試值。
- **驗收**：TC-9 逐位元不變；守衛測試（全部 Z 開頭）綠。

### 2.4 前端安全基線 CSP＋供應鏈 CI（W7, W8）
- vite plugin build 時注入 CSP meta（theme script 自動 sha256）；referrer meta；CI `npm audit --audit-level=high`；Dependabot。
- **驗收**：prod build 的 index.html 含 CSP；stage 手動驗批次 PDF 正常；CI 綠。
- **已知限制**（文件如實記載）：GitHub Pages 無自訂 header → frame-ancestors/X-Content-Type-Options 做不到。

### 2.5 本機加密與密碼鎖（W1, W5 下限；ADR-040）
- `lib/security/{crypto,lockMeta,encryptedStorage}`＋`AppGate/LockScreen`＋persist 條件式 skipHydration；未設密碼＝同步明文 passthrough 零回歸；設定頁「安全與隱私」分頁＋密碼鎖卡。
- **驗收**：設密碼→重整→解鎖→資料在；明文→加密就地遷移；忘記密碼逃生門；既有 clientmount 案例全綠＋新增鎖定案例。

### 2.6 備份檔加密（W6；ADR-040 同套密碼學）
- 匯出可選密碼加密（`.enc.json`）；匯入自動偵測密文。
- **驗收**：roundtrip 測試；錯誤密碼有明確錯誤訊息。

### 2.7 稽核 hash chain＋清除治理（W2；ADR-041）
- prevHash/selfHash＋驗鏈；clearAuditLog 確認字串＋tombstone；importAll 驗鏈附註；設定頁完整性徽章；「完整抹除」入口（個資法§3）。
- **驗收**：竄改偵測/截斷/legacy/tombstone 測試綠；UI 措辭無「防竄改」字樣。

### 2.8 SetupWizard 隱私告知步驟＋ErrorBoundary 鍵修正（W12）
- 精靈插「隱私與資料保護」步驟（勾選放行）；ErrorBoundary prefix 掃描清除。
