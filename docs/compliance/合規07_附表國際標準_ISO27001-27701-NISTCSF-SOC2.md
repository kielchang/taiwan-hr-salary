# 合規07 附表：國際標準——ISO 27001/27701、NIST CSF 2.0、SOC 2

> 前提定位見 [合規00](./合規00_系統定位與適用邊界聲明.md)。

## 1. 對照方法說明

這些標準是**組織級**認證/評鑑框架，認證主體是使用組織的 ISMS/PIMS，不是單一工具。本附表因此採二分法：每個控制標「**可對應**」（本系統的技術控制可直接作為該控制的實作證據）或「**不可對應**」（需後端或組織措施）。目的：讓導入 ISO 27001 的組織知道本系統能貢獻哪些控制證據、哪些必須另行補足。

## 2. ISO 27001:2022 Annex A 相關控制對照（摘選）

Annex A 共 93 控制、四主題（5 組織／6 人員／7 實體／8 技術）。組織（5.x 多數）、人員（6.x）、實體（7.x）主題與工具無關，一律「組織」；以下摘選技術相關者：

| 控制 | 名稱 | 判定 | 說明 |
|---|---|---|---|
| 5.15 | 存取控制 | **不可**（後端） | 無帳號體系；密碼鎖僅裝置層下限 |
| 5.33 | 紀錄保護 | 可（P0 後） | 稽核 hash chain＝防竄改偵測證據；集中保存仍需後端 |
| 5.34 | 隱私與 PII 保護 | 部分 | P0 加密＋本文件體系；程序面組織承接 |
| 8.2 | 特權存取權 | **不可**（後端） | 無權限分級 |
| 8.3 | 資訊存取限制 | **不可**（後端） | 同上 |
| 8.5 | 安全鑑別 | 部分（P0） | 密碼鎖＝單因子本機鑑別；MFA 需後端 |
| 8.8 | 技術脆弱性管理 | 可（P0 後） | npm audit CI gate＋Dependabot |
| 8.12 | 資料洩漏預防 | 部分 | 匯出面收斂（P0 薪資條修補）；DLP 全貌屬組織 |
| 8.13 | 資訊備份 | 可 | 備份匯出＋健康度提醒＋P0 加密 |
| 8.15 | 存錄（Logging） | 可（P0 後） | 稽核軌跡＋hash chain；tamper-evident 定位須如實陳述 |
| 8.16 | 監視活動 | **不可** | 單機無監控 |
| 8.24 | 密碼學之使用 | 可（P0 後） | AES-256-GCM＋PBKDF2（ADR-040 記載金鑰管理） |
| 8.26 | 應用程式安全要求 | 可 | CSP、驗證層 V1–V12、純函數計算層 |
| 8.28 | 安全程式設計 | 可 | TypeScript 嚴格模式＋CI 測試 gate＋元件庫邊界守衛 |

## 3. ISO 27701（PIMS）對照

27701 在 27001 上加控制者（7.x）/處理者（8.x）附加控制。本系統情境只涉控制者線：

| 主題 | 判定 | 說明 |
|---|---|---|
| 7.2 蒐集與處理之條件 | 組織 | 合法基礎文件化（範本01） |
| 7.3 資料主體義務 | 部分（P1） | 近用/可攜（單員匯出）、更正（已具備）、刪除（P0/P1） |
| 7.4 by design/default | 部分（P0） | 資料不出裝置＝正面；預設明文＝待精靈引導改善 |
| 7.5 傳輸/揭露 | N/A | 架構性不發生系統側傳輸；匯出檔屬組織 |

## 4. NIST CSF 2.0 對照（功能層級）

| 功能 | 判定 | 說明 |
|---|---|---|
| GV 治理 | 組織 | 資安政策/角色/供應鏈治理全屬組織；本文件體系＋PMIS ADR 可作證據輸入 |
| ID 識別 | 可 | 合規01 §4 資產/個資盤點 |
| PR 保護 | 部分 | 加密/CSP/備份（可）；身分與存取管理（不可→後端） |
| DE 偵測 | 弱 | hash chain 驗鏈是唯一偵測點；持續監控不可 |
| RS 回應 | 組織 | 範本02 承接 |
| RC 復原 | 部分 | 備份還原機制＋演練屬組織 |

## 5. SOC 2 TSC 對照

| 準則 | 判定 | 說明 |
|---|---|---|
| 安全（CC 系列） | 部分 | 邏輯存取控制（CC6）單機上限；變更管理（CC8）強 |
| 可用性 | 組織 | 靜態站＋本機資料，可用性繫於使用者裝置 |
| **處理完整性** | **強項** | 純函數計算層、TC-9 位元級驗收、V1–V12 驗證、月結兩步＋硬鎖定、建議值/結算值分離——這是本系統對照全部標準中最能直接出證據的一塊 |
| 機密性 | 部分（P0 後） | 加密＋匯出面收斂 |
| 隱私 | 部分 | 告知/同意/保存屬 P1/P2/組織 |

## 6. 小結

二分統計的形狀很清楚：**處理完整性與變更管理是本系統的天然強項**（值得在任何審計對話中主動出示）；**身分/存取/監控是天然弱項**（單機工具的控制上限，呼應合規00 §7）。導入 ISO 27001 的組織可把本系統的 P0 產物（加密、hash chain、CSP、CI 掃描）直接收進 SoA 對應控制的證據清單，但不應期待它承擔 5.15/8.2/8.16 類控制。
