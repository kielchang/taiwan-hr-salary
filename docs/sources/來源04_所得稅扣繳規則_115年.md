## 第二部分：扣繳規則（對應 §5.9 分流）

### 居住者每月薪資：兩法擇一（由員工於免稅額申報表勾選 → 主檔「扣繳方式」欄位）

**方式 A：依薪資所得扣繳稅額表（查表法）**
- 全月應稅薪資未達起扣點 → 免扣繳；達起扣點 → 依「配偶＋受扶養親屬人數」欄查表扣繳
- 起扣點隨扶養人數墊高（每人約 ＋8,417／月）
- **人工控制點**（§7）：官方稅額表為非閉式對照表，達標者由人查表確認稅額
- 115 年度稅額表下載：財政部賦稅署 <https://www.dot.gov.tw/singlehtml/ch_313?cntId=3783c45ec28543838fe285d06d00f3b8>；北區國稅局扣繳專區（含歷年）<https://www.ntbna.gov.tw/multiplehtml/b77824d42c5f462c8cce3fb775057cb0>

**方式 B：固定 5%**
- 稅額＝round(全月應稅薪資 × 5%)；**稅額 ≤ 2,000 免予扣繳**（換算約月薪 4 萬以下免扣）→ 全自動

### 非每月給付（年終、三節、績效獎金）

- 按**給付額 × 5%** 扣繳，免併入全月給付總額
- **單次給付未達 90,501（115 年度起扣標準）→ 免予扣繳**（仍應列單申報）→ 全自動；驗收測試 TC-4／TC-5

### 非居住者

- 全月給付總額 ≤ 44,250 → 6%；超過 → 18%（獎金併入當月給付總額判斷）
- 不適用免稅額申報表、無起扣標準

## 第三部分：免稅額申報表（資料蒐集義務）

| | |
|---|---|
| 表名 | **員工薪資所得受領人免稅額申報表**（薪資所得扣繳辦法） |
| 收件時點 | **到職時、每年 1 月**；員工配偶／扶養異動後 **10 日內**通知更新 |
| 申報內容 | 配偶及受扶養親屬之姓名、出生年月日、身分證統一編號＋扣繳方式勾選 |
| 未填表效果 | 依規定**按固定 5% 扣繳**（合規檢核 V6：收件日為空 → 警示＋預設固定 5%） |
| 對應資料模型 | 員工主檔之「稅務身分／扣繳方式／免稅額申報表收件日」＋眷屬名冊之「報稅扶養」旗標（README §3.2） |
| 表單下載 | 各區國稅局扣繳專區（如北區國稅局連結見上） |

| 義務 | 期限 |

## 查證步驟

1. 開啟稅務入口網 1505 問答，核對：115 年度起扣標準 90,501、兩法擇一、2,000 元免扣、非每月給付 5%、非居住者 6%／18%。
2. 下載 115 年度薪資所得扣繳稅額表 PDF：0 扶養起扣列應自 90,501 起；任一扶養人數欄起扣點與「90,501＋n×8,417」估算值差異應在一個級距（約 250 元）內。
3. 以驗收測試重現（README §9）：TC-6 非居住者 30,000 → 1,800；TC-7 固定 5% 免扣；TC-8 扶養 3 人起扣點 115,752。
