# 來源 05｜二代健保補充保險費

> **文件定位**：本文件是 [README](../../README.md) §4 參數「二代健保補充保費率 2.11%」的**查證依據**，並支撐計算模型 §5.7（個人累計制與投保單位差額制）。儲存格層級的實作見 [附錄A §A2](../appendix/附錄A_Excel公式對照.md)。
> 法源：全民健康保險法 §31（個人）、§34（投保單位）<https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0060001>。主管機關：衛福部中央健康保險署「補充保險費」專區 <https://www.nhi.gov.tw/>。文件編製日 2026/06/11。

---

## 一、個人補充保費 — 獎金類（本設計實作範圍）

受僱者領取**所屬投保單位給付之獎金**（年終、三節、績效、紅利等非經常性給與）時適用。設計公式（README §5.7）：

```
補充保費門檻 ＝ 健保投保金額 × 4
本次計費基礎 ＝ max( 0, 累計獎金 − 門檻 ) − max( 0, 發放前累計獎金 − 門檻 )
            ⟺ min( 本次獎金, max( 0, 累計獎金 − 門檻 ) )
個人補充保費 ＝ round( 本次計費基礎 × 2.11% )
```

法定要點：

- **年度累計制**：每次發放時以「當年度累計獎金」與門檻比較，僅就**新跨越門檻**的部分計費，已計費過的累計額不重複——差分形式直接表達此語意；截斷形式為其代數等價，便於單式實作，兩式可互為驗算。
- 單次計費上限 **1,000 萬元**。
- 扣取時點：**給付時由投保單位代為扣取**，按月彙繳健保署。

### 數字範例（即驗收測試 TC-4）

健保投保金額 36,300 → 門檻 145,200。年度首次發放年終 160,000：

```
計費基礎 ＝ max(0, 160,000 − 145,200) − max(0, 0 − 145,200) ＝ 14,800
補充保費 ＝ round( 14,800 × 2.11% ) ＝ 312 元
```

同年若再發 50,000（累計 210,000，已逾門檻）→ 整筆 50,000 計費 → 1,055 元。

> **與所得稅門檻的獨立性**：獎金的「補充保費」比的是投保金額 × 4（**累計**判斷），「所得稅 5% 扣繳」比的是 90,501（**單次**判斷，見來源04）——兩者法源不同、門檻不同、判斷方式不同，設計上必須是**兩條獨立的計算分支**。同一筆 160,000 年終：補充保費 312、所得稅 8,000，互不相干。

## 二、個人補充保費 — 其他五類（設計範圍外，僅供認知）

兼職薪資所得、執行業務收入、股利、利息、租金五類，單次給付 **2 萬元（含）以上**即就源扣取 2.11%（單次上限 1,000 萬）。若公司有發放此類所得（如外部講師費），由出帳流程另行處理，不屬本薪資計算管線。

## 三、投保單位（公司）補充保費 — 差額制

設計公式（README §5.7）：

```
公司補充保費 ＝ round( max( 0, 當月支付薪資所得總額 − 全體投保金額合計 ) × 2.11% )
```

- 「薪資所得總額」指扣繳憑單認列之薪資（含加班費、獎金等）；投保金額有上限（313,000）且不含獎金——故高薪、加班多、獎金月的差額大。
- 繳納：**次月底前**自行計算繳納（健保署多元繳費管道）。

> **估算標示（P6）**：本設計以「應發合計」概算當月公司補充保費供提列；**正式申報應依扣繳憑單薪資所得總額核計**。兩者差異來源：法定標準內加班費、伙食津貼免稅額等不計入薪資所得，但計入應發合計。

## 查證步驟

1. 健保署官網 → 補充保險費專區：核對費率 2.11%、獎金「投保金額 4 倍」門檻、年度累計制說明與官方試算範例。
2. 以健保署線上「補充保險費試算」輸入 TC-4 案例（投保 36,300、年度累計獎金 160,000）比對 **312 元**。
3. 法條原文：健保法 §31 第 1 項第 1 款（獎金）、§34（投保單位差額）。
4. 每年留意行政院核定之補充保險費率調整公告（與一般保險費率連動檢討）。
