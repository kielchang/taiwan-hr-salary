## 參數：最低工資（月／時）

| | |
|---|---|
| 115 年值 | 月 **29,500** 元／時 **196** 元 |
| 法源 | 最低工資法第 5 條（自 114 年起取代「基本工資」機制） |
| 公告 | 勞動部公告自 115 年 1 月 1 日實施，調幅 3.18% |
| 官方連結 | <https://www.mol.gov.tw/1607/28162/28166/28180/28182/28188/29025/post> |
| 設計用途 | 合規檢核 V1（月薪資總額 ≥ 最低工資，README §8）、各級距表第 1 級、非居住者門檻之基準（×1.5，見來源04） |
| 查證 | 勞動部官網 → 業務專區 → 最低工資；每年第三季審議、年底公告次年值 |

## 參數：勞就保合計費率＋負擔比例

| | |
|---|---|
| 115 年值 | 合計 **12.5%**（勞保普通事故 11.5% ＋ 就業保險 1%）；負擔比例 員工 20%／雇主 70%／政府 10% |
| 法源 | 勞工保險條例第 13 條（費率）、第 15 條（負擔比例）；就業保險法第 8 條 |
| 官方連結 | <https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0050001>（勞保條例）、<https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=N0050021>（就業保險法） |
| 設計用途 | 計算模型 §5.6：勞保自付＝勞保投保薪資×12.5%×20%；勞保雇主＝×70% |
| 年度提醒 | ⚠ 勞保普通事故費率依條例每兩年調升 0.5%，**預定 116 年（2027）起為 12%，合計 13%** |
| 查證 | 勞動部勞工保險局 <https://www.bli.gov.tw/> → 勞工保險 → 保險費 |

## 參數：健保費率＋負擔比例＋平均眷口數＋眷屬計費上限

| | |
|---|---|
| 115 年值 | 費率 **5.17%**（維持不變）；負擔比例 員工 30%／雇主 60%／政府 10%；平均眷口數 **0.56**；眷屬計費上限 **3 口** |
| 法源 | 全民健康保險法第 18 條（費率）、第 27 條（負擔比例）、**第 29 條（眷屬超過三口以三口計）** |
| 官方連結 | <https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=L0060001>；健保署 <https://www.nhi.gov.tw/> → 投保金額與保險費 |
| 設計用途 | §5.6：健保自付＝round(健保投保金額×5.17%×30%)×(1＋計費眷口數)；健保雇主＝×60%×(1＋0.56)。計費眷口數來自眷屬名冊「依附健保」旗標統計（資料模型 §3.2） |
| 查證 | 平均眷口數由健保署公告，多年維持 0.56，仍請年度確認 |
