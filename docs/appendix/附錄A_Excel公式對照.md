> 工作簿的設計理念、架構與維護方法見 [附錄B](附錄B_Excel設計說明.md)，本附錄不重複說明。

## A2. 設計公式 ⇄ 儲存格公式對照

### 投保級距查表（§5.1）→ 員工清單 J–M 欄

```excel
J4: =IF(OR($A4="",$I4=""),"",VLOOKUP($I4,勞保級距表!$B$4:$D$14,3,TRUE))
L4: =IF(OR($A4="",$I4=""),"",VLOOKUP($I4,健保級距表!$B$4:$D$61,3,TRUE))
```

### 眷屬統計（§3.2）→ 員工清單 N／V／O 欄

```excel
N4: =IF($A4="","",COUNTIFS(眷屬名冊!$A$4:$A$203,$A4,眷屬名冊!$G$4:$G$203,"是"))   ← 健保眷屬數
V4: =IF($A4="","",COUNTIFS(眷屬名冊!$A$4:$A$203,$A4,眷屬名冊!$H$4:$H$203,"是"))   ← 扶養人數
O4: =IF($A4="","",MIN(N(N4),參數設定!$C$16))                                      ← 計費眷口數＝min(健保眷屬數, 3)
```

### 月薪資總額與最低工資檢核（§5.0、§8 V1）→ 薪資結構 K／L 欄

```excel
K4: =IF($A4="","",SUM(C4:J4))                                  ← 月薪資總額＝工資項目合計
L4: =IF($A4="","",IF($K4>=參數設定!$C$4,"✓","⚠ 低於最低工資"))
```

### 加班費（§5.3）→ 薪資總表 J 欄

```excel
J4: =IF($A4="","",ROUND($D4/參數設定!$C$19*(E4*4/3+F4*5/3+G4*4/3+H4*5/3+I4),0))
```

### 請假扣款（§5.4）→ 總表 P 欄

```excel
P4: =IF($A4="","",ROUND($D4/參數設定!$C$19*(N4+O4*0.5),0))
```

### 四險保費（§5.6）→ 總表 Q／R／S／Z／AA／AB／AC 欄

```excel
Q4:  =ROUND(員工清單!J4*參數設定!$C$8*參數設定!$C$9,0)                     ← 勞保自付
R4:  =ROUND(員工清單!L4*參數設定!$C$12*參數設定!$C$13,0)*(1+員工清單!O4)    ← 健保自付（先捨單口再乘口數）
S4:  =ROUND(員工清單!M4*N(員工清單!P4),0)                                  ← 勞退自提
Z4:  =ROUND(員工清單!J4*參數設定!$C$8*參數設定!$C$10,0)                    ← 勞保雇主
AA4: =ROUND(員工清單!K4*參數設定!$C$11,0)                                  ← 職保雇主（全額）
AB4: =ROUND(員工清單!L4*參數設定!$C$12*參數設定!$C$14*(1+參數設定!$C$15),0) ← 健保雇主（×1.56）
AC4: =ROUND(員工清單!M4*參數設定!$C$17,0)                                  ← 勞退雇主 6%
```

### 補充保費（§5.7）

```excel
總表 U4（截斷形式）:
  =ROUND(MIN(N(L4),MAX(0,N(T4)-員工清單!L4*4))*參數設定!$C$18,0)
獎金試算 H4＋I4（差分形式）:
  H4: =MAX(0,$G4-$D4)-MAX(0,N($E4)-$D4)            ← 本次計費基礎
  I4: =ROUND($H4*參數設定!$C$18,0)                  ← 個人補充保費
公司差額（總表 E56）:
  =ROUND(MAX(0,SUM(M4:M53)-SUM(員工清單!L4:L53))*參數設定!$C$18,0)
```

兩張表分別採 README §5.7 的兩個等價式——可互為驗算。

### 應稅薪資與稅分流（§5.8–5.9）→ 所得稅扣繳對照 G／H／I 欄

```excel
G4: =薪資總表!M4-薪資總表!J4-薪資總表!L4-薪資總表!S4-MIN(N(薪資結構!G4),參數設定!$C$28)
                                                              ← 當月應稅薪資（估）
H4: =IF($C4="非居住者","—",參數設定!$C$21+$E4*參數設定!$C$22)   ← 估算起扣點＝90,501＋扶養人數×8,417
I4: =IF($C4="非居住者",
        IF($G4<=參數設定!$C$25,ROUND($G4*參數設定!$C$26,0),ROUND($G4*參數設定!$C$27,0)),
     IF(LEFT($D4,4)="固定5%",
        IF(ROUND($G4*參數設定!$C$23,0)<=參數設定!$C$24,0,ROUND($G4*參數設定!$C$23,0)),
     IF($G4<$H4,0,"查115年扣繳稅額表")))                        ← 建議代扣稅額（三分流）
```

建議稅額欄回傳「數值或指引文字」——查表分支輸出文字而非猜測數字，即 README §7 控制點的實作。

### 獎金 5%（§5.9 末段）→ 獎金試算 J 欄

```excel
J4: =IF(身分="非居住者","併當月薪資依6%/18%",
     IF(N($F4)>=參數設定!$C$21,ROUND($F4*參數設定!$C$23,0),0))
```
