破月計薪與員工生命週期

員工狀態有五種：在職／離職／留職停薪／停職／暫時離崗。月中到職、離職或留停時，系統按實際日數逐日加權計薪（破月）：例如月薪 45,000 元、6/16 到職，六月只發約半個月。留停/停職/暫離以「基本資料」員工檔案的區間紀錄管理——每一段有生效日、復職日（未填＝尚未復職）與給薪比例（不填＝採「系統設定 → 公司」的非在職給薪比例預設；停職半薪就是逐案填 50%）。同一人可以有多段紀錄（多次留停、多次復職），復職＝補填該段復職日即可，之後自動恢復全薪，不必改狀態。

  • 勞保費：到職/離職當月按在職天數比例計收。
  • 健保費與勞退提繳：整月計收，不破月。
  • 留停期間的加/退/停/復保，申報名冊會列出提醒供人工向勞健保單位辦理，系統不自動改保費。
狀態改了、日期沒填＝整月照發

狀態設為離職/留停但沒填離職日或生效日，系統只能視為全月在職照發薪資——V8 檢查會用紅色錯誤提醒你補填。
