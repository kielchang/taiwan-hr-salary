一次匯入大量員工

📍 位置：「基本資料」右上「批次匯入」。

初次導入系統、或一次要建幾十名員工時，不必逐一按「新進到職」——用 CSV 檔一次匯入多名員工與其固定薪資。入口：在「基本資料」右上角的「匯入模板」與「批次匯入」按鈕。

  1. 按「匯入模板」下載「員工匯入模板.csv」，內含欄位標題與一列範例。
  2. 用 Excel 或試算表軟體照範例逐列填入員工資料（編號、姓名、到職日、稅務身分、各項固定薪資等），存成 CSV。
  3. 按「批次匯入」選檔，系統開啟預覽視窗逐列驗證：可匯入筆數、錯誤（需修正後重匯）與提醒（如低於最低工資）分色標示。
  4. 確認無誤後按「確認匯入」；有任何錯誤列時按鈕會停用，請修正 CSV 後重新選檔。
同編號會覆蓋既有員工

匯入時若 CSV 內的員工編號已存在，該員資料會被整筆覆蓋且無法自動回復。匯入前請先確認編號不重複，或確定就是要更新該員。
