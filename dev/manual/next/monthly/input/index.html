輸入當月異動

📍 位置：側邊欄 →「薪資結算」

先看一遍實際操作​

當月有人加班、請假、發獎金或有其他加扣款時，就到「薪資結算」的第一步「輸入當月異動」把數字補上。這是一張全員清單：每列顯示員工、本月異動摘要（加班時數、事病假、獎金、加扣項的小標籤），以及即時試算的應發、代扣合計、實發。

  1. 在清單上方用「搜尋姓名／部門…」找到要輸入的員工（欄位也可排序，底部有全公司合計）。
  2. 按該列尾端的編輯開啟異動對話框。
  3. 逐欄填入當月數字（每一欄怎麼填見下節「異動欄位怎麼填」），每填一格下方即時重算。
  4. 按儲存本月異動寫入；其餘沒有變動的員工維持固定薪資，不必開啟。
  5. 全部輸入完，按完成輸入，前往查核。
從待辦直接跳過來

從工作台待辦或查核頁的前往修正跳轉時，系統會直接開啟該員工的異動對話框，不必再搜尋。選「依扣繳稅額表」且薪資達起扣點的員工，清單上會掛需查稅額表填稅額黃色標籤提醒。

已確認月份不能改

該月若已確認結算，清單上方會出現鎖定提示、編輯按鈕反灰；要修改請先到「查核與確認」按取消確認。
