工作台：今天要處理什麼

📍 位置：側邊欄 →「工作台」（首頁）

第一次進站會先看到「第一次使用嗎？」的導覽邀請卡，可按「開始總覽」或「不用了」。每天（或每次進系統）先開首頁的「本月工作台」，一頁看完這個月還欠什麼：每張待辦卡＝數字＋說明＋一鍵直達處理位置；每張卡歸零時各自顯示「目前沒有待辦。」（圖示轉綠），就代表可以進入月結確認。

  1. 先掃上方當期摘要：結算人數、應發總額、實發總額、公司總成本，對本月概況有個底。
  2. 逐張處理七張待辦卡：
    1. 「資料檢查錯誤」：有錯誤未排除前無法確認月結（例如低於最低工資、離職未填生效日、實發為負）。按「前往查核處理」到「查核與確認」頁排除。
    2. 「檢查警告」：建議確認的提醒（加班超時、身分證疑異常、眷屬資料缺漏等），不會擋確認。按「前往查核檢視」逐筆查看。
    3. 「未填代扣所得稅」：還有幾位需要查稅額表或帶入建議值。按「前往所得稅清單」補齊。
    4. 「本月應加保（新進）」：到職日在本月的人數，請於到職當日辦理加保。按「前往加退保名冊」列印或核對。
    5. 「本月應退保（離職）」：離職生效日在本月的人數，請於離職當日辦理退保。同樣按「前往加退保名冊」。
    6. 「本月停保/復保」：本月留停、停職、暫離生效與復職的人數，請辦理停保或復保。同樣按「前往加退保名冊」。
    7. 「投保級距需調整」：目前投保金額與申報基準不一致的人數，2／8 月請辦理級距調整。按「前往級距申報」查看名單。
  3. 若有排程調薪，會多出「排程調薪」卡：已到生效月的項目可按「套用」寫回薪資結構（差額加在本薪、並留下稽核紀錄），或按「取消」放棄排程。
  4. 待辦清空後，按右上角「開始本月結算」進入結算流程（本月已確認時則顯示「查看結算」）。
看到備份提醒請立即處理

資料只存在這台電腦的瀏覽器，清除瀏覽器資料或換電腦即全部遺失。太久沒備份時工作台會跳出提醒，請按「立即匯出備份」把備份檔另存到安全位置。
