需要發外幣薪資時

📍 位置：「系統設定」→「幣別與匯率」分頁

什麼時候做​

公司要用美元、日圓等外幣發放部分薪酬（例如外派津貼、海外獎金）時，先到「系統設定 → 幣別與匯率」分頁把維護中心設好，再回員工資料發放。沒有這個需求的公司完全不用理會——開關預設關閉，全站不會出現任何外幣欄位。

先看一遍：實際操作畫面​

先懂一件事：外幣是獨立金流​

外幣薪資與台幣分開計算、視作獎金：永遠不納入投保級距，也不影響勞健保保費，台幣的應發／實發金額完全不受外幣影響。白話說——多發一筆美元獎金，員工的投保金額、勞健保自付額一毛都不會變；外幣在各報表也是獨立欄位＋台幣約當呈現，不會混進台幣人事成本。

操作步驟​

  1. 按啟用多幣別開關（預設關）。打開後全站才會出現外幣相關欄位。
  2. 新增幣別：填代碼（如 USD）、名稱、符號、小數位，按新增幣別；不再使用的幣別可停用。
  3. 維護匯率：在匯率（對台幣）區選月份，逐幣別填「1 USD = 幾元」——匯率是逐月維護的，每個發放月都要填當月匯率。
  4. 視公司稅務政策決定兩顆開關（兩者預設皆關）：
    • 外幣計所得稅：開＝外幣的台幣約當會併入獎金代扣稅建議與年度扣繳憑單。
    • 外幣計二代健保補充保費：開＝台幣約當併入補充保費的計算基數。
  5. 設定完成後，到員工檔案逐人設定外幣固定項目，或用「基本資料 → 批次薪資」對族群批次發放；當月一次性的外幣調整在薪資結算的異動輸入處理。
未設匯率＝台幣約當以 0 計

某個月沒填匯率時，該幣別當月會標「未設匯率」、台幣約當以 0 計（原幣別金額仍完整記錄）。發外幣前先確認當月匯率已填，否則約當報表與扣繳（若有開啟）會少算。

注意​

  • 兩顆稅務開關屬公司政策判斷，建議與記帳士或會計師確認後再開。
  • 關閉啟用多幣別只是收起全站外幣介面與計算，已輸入的外幣資料不會被刪除。

輔助​
